OCR review queue

What this is: a list of words in the OCR'd text that look like single-character OCR misreads (e.g. Pavment → Payment). Each candidate has a high-confidence suggestion, but nothing is changed automatically.

How to use it: review each candidate against the source PDF (link in each card). Click Approve if the suggestion is correct, Skip if the original is right, or edit the box for a custom fix. Decisions are saved in your browser. When you're done, click Export corrections.json and run python3 scripts/apply_corrections.py to write the fixes into the data files.
